# RepoDeck Development Preview

Local multi-repository workspace manager for Git status, ordinary files and agent configuration.

This is a development preview, not a stable release. Windows x64, macOS Apple Silicon and macOS Intel installers are built separately. Each installer has a SHA-256 file and a JSON manifest identifying its source commit. Binaries are unsigned development builds; OS warnings and macOS distribution restrictions can apply. Do not disable operating-system security controls.

Git is required for repository status. Existing clones and credentials remain managed by Git. Native clean-machine install/upgrade/uninstall, macOS first-launch verification, signing/notarization and bundled third-party license notices are release gates before public stable distribution. Automatic application updates are not implemented.

Use disposable test projects first. Source: MIT; dependencies retain their own licenses. See the repository's release guide and security policy.
