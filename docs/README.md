# RepoDeck Product Documentation

RepoDeck is a local-first desktop application for managing multi-repository software projects in the agentic AI era. It gives developers a consolidated view of every Git and non-Git folder inside an application workspace, including repository health, file changes, ignored files, agent configuration, and project-level settings.

Version 1 is designed to run without a backend, without paid infrastructure, and without forcing a specific Git host. Version 2 keeps an open path for optional cloud and team collaboration.
