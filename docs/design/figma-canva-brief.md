# Figma and Canva Design Brief

## Purpose

This brief can be used to create Figma wireframes, high-fidelity mockups, or Canva presentation material for RepoDeck.

## Design Deliverables

### Figma

Create a desktop app design file with:

- Design system page.
- Workspace dashboard.
- Repository matrix.
- Repository detail.
- File explorer.
- Agent config center.
- Settings.
- Empty states.
- Error states.
- Light and dark theme examples.

### Canva

Create a product/business deck with:

- Problem.
- Target users.
- Product vision.
- V1 local-first scope.
- V2 cloud/team opportunity.
- Core workflow.
- Architecture overview.
- Open-source strategy.
- Roadmap.

## Desktop App Frame

Recommended base frame:

- Desktop: 1440 x 900.
- Compact laptop: 1280 x 800.
- Minimum useful width: 1024.

## Primary Mockup: Workspace Dashboard

Layout:

- Left sidebar width: 240px.
- Main content: flexible.
- Right inspector: 320px.
- Bottom status strip: 32px.

Content:

- Workspace title: RepoDeck Application.
- Summary metrics:
  - 12 repositories.
  - 5 dirty.
  - 2 with conflicts.
  - 8 non-Git folders.
  - 6 agent configs.
- Dirty repository table.
- Agent config summary.
- Non-Git folder warnings.

## Visual Personality

RepoDeck should look trustworthy, practical, and open-source friendly. Avoid glossy SaaS styling. Prefer a focused desktop utility aesthetic similar in seriousness to GitHub Desktop, VS Code, Linear, and TablePlus.

## V2 Visual Placeholder

Settings may include a disabled or clearly marked "Team Sync" area showing future concepts:

- Team workspace.
- Shared status.
- Comments.
- Agent activity.

This should be marked as future-facing and should not imply v1 requires an account.
